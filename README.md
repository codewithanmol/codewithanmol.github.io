# codewithanmol.github.io

Personal home page for **Anmol Tyagi** — cyber security, software and AI.

Claymorphism, hand-written HTML, CSS and vanilla JavaScript. No frameworks, no
build step.

## Run locally

Open `index.html` in a browser, or serve the folder:

```powershell
python -m http.server 8000
```

Then visit <http://localhost:8000>.

## Structure

- `index.html` — content and semantic structure
- `styles.css` — claymorphism design system, layout and animation
- `script.js` — typing effect, scroll reveal and small UI details
- `.nojekyll` — serve files as-is on GitHub Pages

Deployed from `main` with GitHub Pages.
